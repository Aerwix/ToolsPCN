# Como facturar

## Cafeto
### Cliente al Mostrador
Hospedaje = **Cantidad / 1.18**
Restaurant (Vales de Desayuno) = **Cantidad / 1.16**
Lavandería = **Cantidad / 1.16**
Vitrina = **Cantidad / 1.16**

### Factura a RFC
El concepto normalmente sale como **Hospedaje** (Cantidad / 1.18), si el huésped lo desea, se le puede agregar:
- Nombre
- Periodo
- Nro. Habitación

#### Excel - Facturación RFC - Cafeto
En el recuadro de abajo se agrega en el siguiente formato, cuando son de **recepción**:
```Hab. 130 - Periodo 25-27/Sept Nombre + Hospedaje + Vales + # de Vales ```
